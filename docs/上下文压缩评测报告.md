# HarnessAgent 上下文压缩评测报告

评测日期：2026-09-29。模型：`deepseek-v4-flash`，通过项目配置的真实 API 调用。公开的逐次运行数据见 [`evals/results/context-compaction-2026-09-29.json`](../evals/results/context-compaction-2026-09-29.json)。

## 评测目标与方法

比较同一任务在 `full`（不启用自动上下文压缩）与 `compact`（启用自动上下文压缩）两种模式下的任务完成率和上下文负载。每种模式运行 15 次，共 15 组成对样本、30 次 Agent 运行。两组在每个样本上使用同一模型、初始文件、历史记录、工具集合、轮数预算和独立验收标准；执行顺序交替，并为每次运行建立新工作区。

样本由三类任务组成，每类 5 组：

| 任务 | 样本变化 | 独立验收 |
| --- | --- | --- |
| 编码 | CSV 解析器运行 3 次；双文件工具函数运行 2 次 | 工作区外的 Python 验收脚本 |
| 历史信息召回 | 5 个固定种子的不同准确值，分布在第 1、4、14、21、24 个历史工具输出中 | `answer.txt` 与目标值一致 |
| 摘要保真 | 准确值位于超长普通历史消息的开头、中间或末尾 | `answer.txt` 与目标值一致 |

历史工具输出配置为 28 组、每组约 5000 字符。成功要求独立验收通过且 Agent 正常结束；超时、运行错误或验收失败都计入分母并视为失败。输出准确值时允许文件末尾有一个常规换行符（LF 或 CRLF），其余内容必须完全一致。

## 结果

| 任务 | 不压缩完成率 | 压缩完成率 | 不压缩累计输入字符中位数 | 压缩累计输入字符中位数 | 降幅 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 编码 | 5/5 | 5/5 | 478,067 | 164,901 | 65.5% |
| 历史信息召回 | 5/5 | 5/5 | 780,970 | 163,509 | 79.1% |
| 摘要保真 | 5/5 | 5/5 | 282,846 | 136,574 | 51.7% |

总体完成率两组都是 **15/15（本批样本观察值 100%）**，上下文超限错误都是 0。压缩组在 15/15 次运行中触发了压缩；摘要保真任务共产生 5 次额外摘要调用。

30 次运行中，不压缩组的模型请求累计输入为 **7,608,313 字符**，压缩组为 **2,500,737 字符**，减少 **67.1%**。这个指标包含系统提示、消息和工具定义，是字符量，**不是 token、API 费用或实际内存占用**。压缩组的模型调用数由 54 次增至 83 次（增加 53.7%）；摘要任务的成功运行耗时中位数由 2.60 秒增至 14.98 秒。输入缩短伴随检索和摘要调用开销，不能据此声称成本或速度下降。

## 验收修正与边界

首次评分将 4 次正确答案判为失败：模型写出的值完全正确，但 `answer.txt` 末尾带有 Windows 常规换行 `\r\n`，旧规则按字节严格相等。修正后对已保存的 30 份工作区产物重新运行独立验收，**没有重新调用模型**；原始 `summary.json` 保留，修正结果另存为 `summary.regraded.json`，并导出上述公开数据。修正前两组各为 13/15，修正后两组各为 15/15。

这是一组固定任务模板和合成历史上的小样本试验，不是通用 Agent 基准。编码部分只有两道不同题，其余变化主要来自随机种子与信息位置；15/15 不能推断总体成功率为 100%，也不能证明压缩提高了任务质量。后续要验证泛化，需要更多真实长任务、不同上下文压力、不同模型，以及提供商返回的真实 token 用量和费用。

## 复现

在项目根目录配置真实模型 API 后运行：

```powershell
python -m evals.context_compaction --provider deepseek --case all --repeats 5 --timeout 240
```

脚本将原始结果写入 `.scratch/evals/context-<时间>-deepseek-<编号>/summary.json`。修正旧批次评分和导出可审阅数据：

```powershell
python -m evals.regrade_context_compaction <summary.json 路径>
python -m evals.export_context_compaction <summary.regraded.json 路径> <输出 JSON 路径>
```

可用于简历的表述：

> 设计并实现 Agent 上下文压缩对照评测，覆盖编码、历史信息召回和摘要保真 3 类任务；在真实模型的 15 组成对样本中，压缩前后均通过 15/15 次独立验收，压缩组累计请求输入字符量减少 67.1%，并记录额外检索与摘要调用开销。
