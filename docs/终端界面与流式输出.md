# 终端界面与流式输出

## 启动

```powershell
cd D:\HarnessAgent
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m agent --tui --workdir "D:\btest"
```

界面是终端应用，推荐使用 Windows Terminal / PowerShell 窗口。增加 `--teams` 开启后台队友，增加 `--full` 同时开启团队和长期记忆。原来的普通 CLI 和单次任务输出方式继续保留；只有显式使用 `--tui` 才进入新界面并启用用户回答的流式显示。`--quiet` 与 `--tui` 不能同时使用。

免费演示（会在指定的临时工作区创建 greeting.py）：

```powershell
.\.venv\Scripts\python.exe -m agent --tui --mock --demo --workdir .scratch\tui-demo
```

## 使用

- Enter 发送；Alt+Enter、Shift+Enter 或 Ctrl+J 换行。不同终端对组合键支持不同，Ctrl+J 可作为换行备选。
- Ctrl+P / Ctrl+N 浏览当前会话的输入历史；Ctrl+L 回到输入框。
- Ctrl+C 请求停止当前任务；空闲时清空输入。Ctrl+Q 或 `:quit` 退出。
- 点击工具卡片展开参数与输出；错误卡片自动展开。`--verbose` 让工具卡片默认展开，不直接向终端交错打印日志。
- 右侧显示会话统计和后台队友状态；窄于 100 列时自动隐藏侧栏。
- 权限确认会打开弹窗，显示调用者、工具、理由与参数；Y 允许本次，N / Escape 拒绝。默认聚焦拒绝。已有 allow/deny 配置继续生效。
- `:status`、`:tools`、`:todos`、`:tasks`、`:team`、`:skills`、`:memory`、`:mcp`、`:notes`、`:trace`、`:help` 是本地命令，不发模型请求。`:goal <条件>` 会执行任务并可能产生模型用量。

输入在任务执行时可以编辑，但不会并行提交第二个主任务。若用户向上滚动查看旧消息，后续输出不强制拉回底部。

## 实现

`agent/tui.py` 使用 Textual 管理界面。模型和工具运行在工作线程；通过线程安全队列发送 `UIEvent`，由 UI 线程统一更新消息、工具卡片和状态。
主 Agent、一次性子 Agent、后台队友的事件带有各自的 owner 与独立调用编号，文本片段不会混入同一个回答块。
UI 事件与调度用的 on_event、磁盘诊断日志分开，不改变队友根据工具活动判断进度的逻辑。

`agent/llm.py` 在传入文字回调时使用 SDK 的消息流，边接收公开 text_delta 边发送显示事件。
不显示 thinking、工具 JSON 片段、摘要或记忆调用的内容。完整结束后仍返回原来的 LLMResponse；供应商最终 usage 只汇总一次，不按文字片段重复累计。

工具执行仍等待整条响应完成。缺少 message_stop 的断流会报错，不接受快照中的工具调用；max_tokens 截断仍走原有丢弃和有限恢复逻辑。
界面上已经显示的部分文字会标记为未完成。流式不自动重放中断请求，避免重复输出或额外用量。

原生和 Mock 客户端支持文字流；未声明该能力的自定义 LLM 客户端继续返回完整响应，由界面一次显示。

## 停止与输出边界

停止是协作式的：收到 Ctrl+C 后拒绝待处理的权限确认，跳过尚未执行的工具，在后续流事件或循环边界检查停止标记。
已经执行的修改不会回滚；正在阻塞的网络读取或命令可能需要先返回。不会把仍在运行的工作线程误显示成可以立刻启动第二个任务。
取消时，一批工具中未执行的调用会补齐 CANCELLED 结果，保留对话工具调用/结果的配对。

工具在界面中最多预览 8000 字符，并显示实际返回长度；这不改变工具返回给模型的原始内容。
模型的后续上下文仍受已有工具输出预算与压缩规则约束。bash 自身仍在命令结束后返回结果，不是命令 stdout 的实时流。

不把 UI 文本片段写入 runs，也不把界面事件加入模型对话。已有转录、记忆、诊断规则继续按各自配置执行。

## 离线验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_streaming.py -v
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_tui.py -v
```

SSE 假事件测试覆盖断流、完整工具参数、截断恢复、取消和 token 汇总；无头 UI 测试覆盖输入、历史、展开、审批、线程消息和窄屏布局。不需要模型 API 密钥，也不验证真实供应商的网络连通性。
